# Rahat Hoque — Portfolio

Static, responsive portfolio website suitable for GitHub Pages.

## Run locally

Open `index.html` in a browser. No build step is required.

## Personalize

- Replace `assets/images/profile-placeholder.svg` with your photo (keep the same filename, or update the image source in `index.html`).
- The downloadable CV is stored at `assets/documents/Rahat_Hoque_CV.pdf`.
- Add your LinkedIn profile in `index.html` if you want it shown alongside GitHub and CodePen.

Animations use GSAP from jsDelivr and automatically respect reduced-motion settings.
